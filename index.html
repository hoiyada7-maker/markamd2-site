marka.md

marka.md is a local-first desktop markdown editor (built with React and Tauri) for macOS, Windows and Linux. It is made for managing the notes you share with AI: write in a live editor with rendered preview, work with files in tabs and a folder sidebar, and stage several notes into one AI-ready context bundle. Your files stay on your machine until you choose to copy or share them.

Features

  • Live editor with rendered preview, syntax highlighting and mermaid diagrams
  • File tabs, folder sidebar, search and session restore
  • Context tray that bundles multiple notes into one AI-ready copy
  • CSV preview and PDF export
  • Themes and multiple interface languages

Google Drive integration

Google Drive is optional. If you sign in with Google, marka.md lets you upload a markdown file, together with the local images it references, to a Google Drive folder that you choose. You can also download a markdown file that you pick from Drive, together with the images it references in the same Drive folder, into a local folder that you choose. Everything runs on your device; there is no marka.md server.

See the Privacy Policy for the exact Google permissions requested and how data is handled.

English

marka.md

marka.md는 macOS, Windows, Linux에서 사용하는 로컬 우선(local-first) 데스크톱 마크다운 편집기입니다(React와 Tauri 기반). AI와 공유하는 노트를 관리하도록 만들어졌습니다. 실시간 편집기와 렌더링 미리보기, 파일 탭과 폴더 사이드바, 여러 노트를 하나의 AI용 컨텍스트 묶음으로 준비하는 기능을 제공합니다. 사용자가 직접 복사하거나 공유하기 전까지 파일은 내 컴퓨터를 벗어나지 않습니다.

기능

  • 렌더링 미리보기, 구문 강조, mermaid 다이어그램을 지원하는 실시간 편집기
  • 파일 탭, 폴더 사이드바, 검색, 세션 복원
  • 여러 노트를 하나의 AI용 묶음으로 복사하는 컨텍스트 트레이
  • CSV 미리보기 및 PDF 내보내기
  • 테마 및 여러 인터페이스 언어

Google Drive 연동

Google Drive 연동은 선택 사항입니다. Google 계정으로 로그인하면 마크다운 파일과 그 파일이 참조하는 로컬 이미지를 사용자가 선택한 Google Drive 폴더에 업로드할 수 있습니다. 또한 Drive에서 선택한 마크다운 파일과, 같은 Drive 폴더에 있는 참조 이미지를 사용자가 선택한 로컬 폴더로 다운로드할 수 있습니다. 모든 작업은 사용자의 기기에서 실행되며 marka.md 서버는 없습니다.

요청하는 Google 권한과 데이터 처리 방식은 개인정보 처리방침을 참고하세요.
